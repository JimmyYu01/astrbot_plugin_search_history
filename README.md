# astrbot_plugin_search_history

让 AstrBot 自动缓存搜索记录，并允许用户使用指令进行查询。

## 功能

- **自动缓存**：监听 LLM 的工具调用结果，命中搜索类工具时，将「搜索参数 + 搜索结果」按**会话**缓存，每个会话保留最近 **10** 条（新的排在最前）。
- **指令查询**：查看当前会话的搜索列表，并可展开某一条记录，以**合并转发**形式输出标题与链接。

## 安装

放入 AstrBot 的 `data/plugins/` 目录，或直接在插件页安装。无需配置项。

## 使用

先正常对话让 AstrBot 触发搜索，然后在本会话中发送指令（默认前缀为 `/`）：

| 指令 | 别名 | 说明 |
| --- | --- | --- |
| `/search_history` | `/搜索记录` | 列出当前会话的搜索记录概览 |
| `/search_history <编号>` | `/搜索记录 <编号>` | 展开对应记录的搜索结果 |

概览形如：

```
1.搜索：<关键词>
2.抓取：<url>
```

展开时以**合并转发**输出：

- 第一条消息为搜索参数（`参数：{...}`）。
- 其后每条结果一条消息，格式为 `[编号] 标题` 换行 `链接`。
- 编号即搜索结果中的 `index`，形如 `12bf.1`。

> 仅支持展开**网页搜索**类记录；网页抓取类记录只会在概览中列出，展开时提示「不支持输出此搜索记录」；无法识别的记录提示「未识别此搜索记录」。

## 支持的搜索工具

覆盖 AstrBot 内置的联网搜索 / 网页抓取工具：

| 类别 | 工具名 |
| --- | --- |
| 网页搜索 | `web_search_baidu`、`web_search_tavily`、`web_search_bocha`、`web_search_brave`、`web_search_firecrawl`、`web_search_exa`、`web_search_anysearch` |
| 网页抓取 | `tavily_extract_web_page`、`firecrawl_extract_web_page`、`exa_get_contents` |

## 限制

- 记录保存在内存中，按会话（`unified_msg_origin`）隔离：**重启或卸载插件后清空**，且换会话 / 群查不到其它会话的记录。
- 每会话上限 10 条，超出后最旧的记录被淘汰。
- 展开记录依赖搜索结果 JSON 中每项的 `index`、`title`、`url` 字段，格式不符合时输出失败提示。
